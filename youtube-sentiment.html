01 / Project overview

Understanding audience sentiment in YouTube comments

This group project uses the YouTube Data API and a pretrained text classification model to explore positive and negative sentiment in comments on an iPhone 16-related video. The shared notebooks document both the initial implementation and a proposed hybrid emoji + NLP pipeline.

Data source

YouTube Data API v3

Fetches top-level comments from a selected public video, with pagination and a configurable maximum.

Language model

DistilBERT (SST-2)

Uses distilbert-base-uncased-finetuned-sst-2-english for English binary sentiment classification.

Output

CSV-ready results

Pairs comment text with predicted sentiment labels using pandas. No accuracy metric is asserted.

03 / Methodology

Technical details

Retrieval & filtering

The API client requests up to 100 comments per page and follows page tokens. A configurable keyword list filters some off-topic comments.

Emoji-aware logic

Positive and negative emoji sets provide a lightweight rule-based signal. Ambiguous comments can pass to the language model.

Text classification

The Transformers sentiment pipeline classifies text. Pandas structures the predictions and supports export and a sentiment-distribution chart.

04 / Implementation review

What the source code actually shows

The original Python script defines analyze_comments twice. The second definition replaces the first and calls the pretrained sentiment pipeline directly, meaning the emoji-aware analyze_comment function is not used in that script’s final batch-processing step.

The separate demonstration notebook documents the intended hybrid approach using analyze_comment per comment. Neither supplied notebook includes saved execution outputs or a validated accuracy / precision / recall score.

Portfolio integrity: The workflow graphic above is conceptual. Sentiment percentages and sample comments are deliberately omitted until results are verified. This project was completed collaboratively; specific individual contributions have not been attributed without confirmation.
